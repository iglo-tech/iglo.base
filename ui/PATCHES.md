# Changes against upstream's `ui/`

This directory is upstream PocketBase v0.41.0's `ui/` (commit `f6baa0c43f379de21cd806de97ad6a2b8ca97b83`), copied unchanged except for the entries below (`docs/design/08-admin-ui.md`). To compare, diff it against upstream's `ui/`; only these changes should show. To take a later upstream dashboard, copy it again and re-apply this list by hand.

## Build

1. **Not copied:** `dist/` (generated by the build, ignored here), `embed.go` and `embed_no_ui.go` (Go embedding; iglo.base embeds the build output with `scripts/ui/build.ts`).
2. **`package-lock.json` replaced by `bun.lock`:** Bun is the package manager. The lockfile was migrated from upstream's `package-lock.json` with the same resolved versions (vite 8.2.1, pocketbase 0.28.1, leaflet 1.9.4). `scripts/ui/build.ts` runs `bun install --frozen-lockfile` and `vite build` under Bun.

## Behavior

3. **`src/main.js`: `/_/extensions.js` is not loaded.** The app is marked ready at once. No dashboard extensions (D5); the server still answers `/_/extensions.js` with an empty script for cached old builds.
4. **`src/settings/sync/pageImportCollections.js`: the import hint names only JS migrations.** The "Go" link and its " or " are removed; Go migrations do not exist, JS migrations do (D23).
5. **`src/settings/backups/backupRestoreModal.js`: "Applies all migrations that are missing" becomes "Applies the system migrations that are missing".** Only system migrations exist.

## Branding (D17)

6. **Page title:** `index.html` `<title>` is `iglo.base`.
7. **Logo and favicons:** `public/images/logo.svg`, `logo_white.svg`, `favicon.png` and `favicon_prod.png` are the iglo.base monogram (same sizes as upstream's files).
8. **Product name in dashboard text:** "PocketBase" becomes "iglo.base" in `src/auth/pageInstaller.js` (page title), `src/settings/storage/pageStorageSettings.js`, `src/settings/mail/pageMailSettings.js`, `src/settings/backups/pageBackupsSettings.js`, `src/settings/sync/pageExportCollections.js`, `src/settings/application/trustedProxyAccordion.js` (5 places), `src/collections/oauth2/larkOptions.js` and `src/collections/collectionRulesTab.js`. The `PocketBase` JS SDK class and the API preview code samples (`src/apiPreview/`) are unchanged: they name the SDK, not the product.
9. **Footer:** `src/store.js` labels the version link `iglo.base <version>`.
10. **Documentation links (`.env`):** `PB_DOCS_URL` and the `PB_*_DOCS` links point at iglo.base's documentation in this repository (`https://github.com/iglo-tech/iglo.base/tree/main/docs`, [open question 1](../docs/design/11-open-questions.md); the pages are written in M7.2). The SDK links stay.
11. **Version (`.env`):** `PB_RELEASES` points at iglo.base's releases and `PB_VERSION` defaults to `(untracked)`. `scripts/ui/build.ts` sets `PB_VERSION` to the executable's version (`src/cli/root.ts`) at build time.
