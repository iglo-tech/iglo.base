# M5.7: static files, CORS and a records list against upstream

What do `--publicDir` static files, the SPA fallback and the CORS middleware cost, and does the records list keep its speed with CORS and `RealIP` in front of it? Requests per second and latency over HTTP for upstream v0.41.0, this branch and `main` before M5.7.

## Setup

| | |
|---|---|
| Date | 2026-11-02 |
| Machine | AMD Ryzen 5 1600 (6 cores), Linux 6.12 (Debian 13), VM with dynamic memory (2–16 GiB; about 8 GiB available during the runs), shared with other work: run-to-run spread is large |
| Bun | 1.4.4 |
| Upstream | PocketBase v0.41.0 release binary (`.upstream/bin/pocketbase`) |
| Before | `main` at `bffed3a`, built with `bun run build` |
| Command | `nice -n 10 bun test/perf/serve/bench.ts --requests 8000 --before <main executable>` (the first run with the default 5,000 requests) |

Every server serves its own copy of the vendored fixture and the same `pb_public`: a 4 KiB `app.js`, a 1 MiB `photo.png` and an `index.html`. Each workload is a guest's: 500 warm-up requests, then the measured ones, 8 in flight over keep-alive connections, one server at a time. `main` has no static route (M0.1 answers every path outside the routes with `404 File not found.`), so its static rows measure that 404.

## Findings

- Static files are served at upstream's speed: the 4 KiB script within the spread of upstream's runs (one slow upstream run, 1,698/s with a 66 ms p99, looks like host noise), the 1 MiB image at the same rate, as both are bound by sending the bytes. A file opened by path goes to Bun as a file `Blob`, so it is streamed, not read; only a file of a type for which `Bun.serve` would add a `Content-Disposition` header (not text, image, font, audio, video, JSON or WASM) is read into memory, and only up to 16 MiB (`src/apis/static-fs.ts`).
- The SPA fallback is slower than upstream (about 0.6×): every missing path stats the path, then opens `index.html`, on the event loop; upstream does the same work on a goroutine per request. It answers in about a millisecond.
- The records list is unchanged by M5.7: the CORS middleware and `RealIP` (no trusted headers configured) are within the spread of `main`, with and without an `Origin`. The list's gap to upstream is the one recorded for M2.4 (`docs/perf/M2.4-records-read.md`), carried to M7.
