# M3.7: bound values in the database access layer

`replacePlaceholders` (`src/db/dbx/query.ts`) gained one `instanceof BoundValue` check per param, so a migration's Go values bind what `database/sql` binds. No other query code changed, and only migrations create a `BoundValue`.

| | |
|---|---|
| Date | 2026-10-31 |
| Machine | AMD Ryzen 5 1600 (6 cores), Linux 6.12 (Debian 13), VM with dynamic memory |
| Bun | 1.4.4 |
| Commits | before `ab57877`, after `task/M3.7-js-migrations` |

20 million `replacePlaceholders` calls with six params (number, string, null, bytes, float, string), three rounds in one process, one after the other. Other work may have run on the host.

| | Round 1 | Round 2 | Round 3 |
|---|---|---|---|
| before, ns per call | 84.1 | 74.6 | 73.4 |
| after, ns per call | 70.9 | 87.8 | 84.8 |

The difference is within the rounds' noise (at most 14 ns per call of six params), and a query's run costs microseconds. Query, record and batch benchmarks were not rerun.
