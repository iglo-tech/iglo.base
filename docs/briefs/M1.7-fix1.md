## Second fixer (after the lead's decision on finding 3)

The first Terra fixer diagnosed finding 3 and stopped as instructed ([evidence](https://github.com/iglo-tech/iglo.base/pull/18#issuecomment-6470708640)): Linux Bun SQLite 3.53.4 has `legacy_alter_table=0` and rejects the view-of-view rename; macOS system SQLite 3.51.0 has `legacy_alter_table=1` and accepts it, leaving a broken view. Upstream's embedded SQLite runs with the SQLite default `legacy_alter_table=OFF`. Lead decision: every iglo.base connection sets `legacy_alter_table(OFF)` next to upstream's pragmas, so the rename check matches upstream on any system SQLite. Findings 1 and 2 were not started.
