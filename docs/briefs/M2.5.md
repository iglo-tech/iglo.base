# Brief M2.5 (with M3.4)

Written by the chief of staff on 2026-10-29 from the work plan's template. Plan change (lead decision, for owner review): M3.4 (collections write, import, truncate, view dry run) is folded into M2.5. Both port `apis/collection.go`, together about 360 upstream lines plus `collection_import.go`, and the usable-first order runs them back to back; one task saves a review cycle and lets the dashboard (M6.1) use the full collections API at once.

```text

  - The host has limited memory: run `bun run check` and `bun run test:reference` one after the other, never in parallel, and never write into tracked fixtures.
  - Branch: task/M2.5-collections-api. PR title: "M2.5: Collections API (with M3.4)".
```
